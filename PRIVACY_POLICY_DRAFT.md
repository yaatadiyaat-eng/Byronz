# Draft Privacy Policy Byronz

Tanggal berlaku: 23 April 2026

Byronz adalah aplikasi AI yang dibuat oleh Muhammad Adiyaat Alfathi untuk membantu percakapan, analisis file/gambar, pembelajaran English, coding, bisnis, dan pengetahuan umum.

## Data yang dapat digunakan aplikasi

- Teks chat yang dikirim pengguna untuk menghasilkan jawaban AI.
- File atau gambar yang diunggah pengguna untuk dianalisis.
- Mikrofon hanya saat pengguna memakai fitur English Call.
- Lokasi perangkat hanya untuk menampilkan informasi lokasi/cuaca real-time jika pengguna memberi izin.

## Tujuan penggunaan data

Data digunakan untuk menjalankan fitur utama Byronz, memberikan jawaban AI, menganalisis input pengguna, dan menyesuaikan pengalaman aplikasi berdasarkan mode yang dipilih.

## Penyimpanan dan pengiriman data

Pada mode lokal, data diproses di perangkat/server lokal pengguna. Pada versi publik, pesan atau file dapat dikirim ke backend Byronz agar AI dapat memberikan jawaban. Jangan mengunggah data sensitif jika tidak ingin diproses oleh sistem AI.

## Izin perangkat

- Mikrofon: digunakan untuk percakapan suara pada English Call.
- Lokasi: digunakan untuk menampilkan lokasi, suhu, cuaca, dan tanggal/waktu real-time.
- File/gambar: digunakan hanya saat pengguna memilih file atau gambar untuk dianalisis.
